Ship ESM only, with the package `exports` generated by tsdown.

- The CommonJS build (`dist/index.cjs`) is removed. On Node.js 20.19+ and 22.12+, `require('compute-scroll-into-view')` still works through `require(esm)` and returns `{ compute }`.
- TypeScript projects with CommonJS files must use `"module": "nodenext"`. With `"module": "node16"`, TypeScript reports TS1479 when CommonJS files import an ES module. ESM files and `"moduleResolution": "bundler"` are unaffected.
- `exports` is now `{ ".": "./dist/index.js" }`. The `source` export condition and the `source` and `typings` fields are removed. `types` replaces `typings`.
